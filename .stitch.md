# Stitch AI Workspace Rules: P2P Mesh Frontend

## 1. Core Tech Stack
* **Framework:** React 19 (TypeScript)
* **Build Tool:** Vite 8
* **Routing:** React Router DOM v7
* **3D Visualization:** Three.js (Must be used for all 3D mesh rendering panels)
* **Telemetry & Charts:** Recharts (Must be used for printer telemetry, hotend temp data, and progress tracking)
* **Icons:** Lucide React

## 2. Design System & Palette Tokens
Ignore default white, blue, or generic Tailwind color palettes. Strictly enforce the following custom scheme:
* **Primary Accent (Actionable):** Bloody/Red-Orange `rgb(188, 56, 35)`. Use this exclusively for primary buttons ("Generate & Print", "Start Simulator"), active links, progress bar fills, and active Recharts data lines.
* **Core UI & Structure:** Corporate Grey `rgb(110, 111, 113)`. Use this for borders, secondary buttons, unselected states, Recharts axes, and secondary text. 
* **Base Canvas:** Use a stark, clean contrast layer (e.g., `#1A1A1A` for dark mode or `#F9F9F9` for light mode) to ensure the Corporate Grey and Bloody Orange remain highly legible. Ensure WCAG contrast compliance for all typography.

## 3. Component Architecture & Aesthetics
* **Layout Philosophy:** Symmetrical, clean, modern, and professional. 
* **Grid Systems:** Rely heavily on strict CSS Grid layouts. The main dashboard and job detail views (e.g., Prompt, 2D Blueprint, 3D Mesh, Control Panel) must be evenly distributed in perfectly symmetrical columns.
* **Containers & Cards:** * Sharp or minimally rounded corners (maximum `4px` border-radius).
  * Borders must be a solid, thin `1px` line using the Corporate Grey token.
  * Do not use soft, fuzzy drop shadows. Rely on flat design and solid borders to separate spatial elements.
* **Forms & Inputs:** * Input fields (like the Prompt text area or Settings URLs) must use flat styling with Corporate Grey borders that highlight to Bloody Orange on focus.

## 4. Specific View Instructions
* **3D Viewer Panels:** Ensure Three.js canvas containers are responsive, maintain aspect ratios, and feature a minimalist UI overlay for camera controls.
* **Status Badges:** Abandon default green/red. Use the Corporate Grey for dormant/stopped states and Bloody Orange for active/processing states. Maintain sharp, professional pill shapes.
