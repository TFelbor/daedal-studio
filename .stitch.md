# Frontend design rules: P2P Mesh app

The app speaks the marketing site's language: a near-black ground, one orange for
actions, condensed display type over Barlow, hairline rules and registration marks.
Source of truth for the look is `web/src/global.css` — every token below is defined
there, and **no component may hard-code a hex, a font name, or a rule colour.**

## 1. Core tech stack

- **Framework:** React 19 (TypeScript)
- **Build:** Vite 8
- **Routing:** React Router DOM v7
- **3D:** Three.js — all mesh rendering
- **Charts:** Recharts — telemetry, temperatures, progress
- **Icons:** Lucide React, `strokeWidth={1.5}` (thin, technical — never heavier)

## 2. Palette

This is a **single-theme design.** The ground is the identity, so there is no light
variant and no theme toggle. Do not add one, and do not introduce a colour outside
this set.

| Role | Token | Value |
|---|---|---|
| Page ground | `--void` | `#0d0d0d` |
| App surface (ruled with the 56px module) | `--ground` | `#171717` |
| Raised surface | `--raised` | `#1e1e1e` |
| Ink | `--ink` | `#f2f0ed` |
| Muted ink | `--ink-58` … `--ink-28` | alpha ladder on the ink |
| **Action** | `--accent` | `#eb8724` |
| Action pressed | `--accent-press` | `#c26f18` |
| Rules | `--rule-strong` / `--rule` / `--rule-row` / `--rule-sub` | ink at .2 / .13 / .1 / .08 |

**Status colours are status-only** — `--ok` `#4fae7f`, `--run` `#5c9ce6`, `--bad`
`#d9564f`. They never mark something clickable, so a colour always means state. The
orange is the reverse: it only ever means "you can act here". Keeping those two sets
disjoint is what makes the interface readable at a glance; blending them is the
easiest way to break this design.

## 3. Type

- **`--font-heading`** — Barlow Condensed, weight 600, tight tracking. Every heading,
  every large numeral, every primary button label.
- **`--font-body`** — Barlow. Body copy, labels, secondary buttons.
- **`--font-mono`** — system monospace. IDs, seeds, paths, dimensions, timestamps,
  log output: anything a person would copy or compare digit by digit.
- **Micro-labels** title blocks: 10px, uppercase, `.2em` tracking, muted ink
  (`.label`). They are the connective tissue of the layout — prefer one over a
  larger heading when labelling a block inside a page.

## 4. Objects

Cards, figures, plates and primary buttons are **wireframe objects**: square corners
(no radius anywhere), one hairline border, and four `+` registration marks straddling
the corners. Render them with `<Blueprint>` from `web/src/components/Blueprint.tsx`,
or `<Marks />` inside an element that already has its own border.

- **Never round a corner.** No `border-radius` except the 6px status dot.
- **Never drop the marks** from a framed object.
- **Never use a drop shadow.** Depth comes from the three grounds and the rules.
- Cards are line drawings, not filled panels. The solid accent primary button is the
  one deliberately filled object on the board.

## 5. Layout

Modular grid, strong horizontal and vertical rhythm, visible structure. Equal-width
cells divided by hairlines rather than gaps-plus-boxes. Tables are hairline rows: one
rule between rows, no cell borders, no zebra striping. Page bodies sit on `.surface`
(the ruled ground) inside `.sheet` padding.

Numbering (01–05) is used **only** where the content is genuinely ordered — the five
pipeline phases, the settings sections. It is structure, not decoration.

## 6. Interaction

Every interactive element gets a themed hover and a visible `:focus-visible` ring
(2px accent, 2px offset) — never a browser default. Disabled controls drop to 45%
opacity and keep their caption explaining what would enable them.

Motion has exactly two sanctioned registers, and everything animated dies under
`prefers-reduced-motion` (drawn surfaces — canvas, WebGL — must check
`prefersReducedMotion()` themselves, the media query cannot reach them):

- **State**: the pulse on a running indicator.
- **The handoff**: the pipeline is a production line reading left to right, and
  every artifact arrives from upstream. Three moves, defined once in `global.css`
  and timed only by `--motion-quick`/`--motion-move` with `--motion-ease`:
  `p2p-arrive` (a new phase output drifts onto the stage, a short leftward offset
  — never a slide from off-screen), `p2p-rise` (the blocks an output brings with
  it), and `p2p-sweep` (one accent pass along a rule at the moment of a handoff —
  the single orchestrated gesture of the running view; do not add a second).
  Decoration that moves for its own sake stays banned.

## 7. Copy

Write from the user's side of the screen. An action names what happens ("Generate &
print", then "Printing"). Empty states say what will appear here and offer the action
that fills them. Errors say what failed and what to do, in the interface's voice —
never an apology, never vague. Sentence case throughout except the tracked
micro-labels.
